### Aira · Architecture / pre-MVP

I'm architecting a local-first memory and context layer for AI tools. The design focuses on user-controlled knowledge that can move across assistants and development environments.

Current design work covers:

- Typed, scoped, versioned memory with provenance and an auditable lifecycle.
- Hybrid retrieval using SQLite FTS5 and vector search.
- A provider-independent core with REST and MCP integration surfaces.
- Permission checks before retrieval and inspectable context assembly.

Architecture and MVP planning are in progress; these are design decisions, not claims of a released implementation.

[Architecture overview](https://akashtech.vercel.app/#project-aira)
